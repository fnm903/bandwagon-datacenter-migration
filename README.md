## 搬瓦工切换数据中心是什么？

> **搬瓦工切换数据中心**，指用户通过 KiwiVM 控制面板中的 Migrate to another DC 功能，将已有的 VPS 实例物理搬迁至另一个数据中心节点，全程免费、数据保留，迁移完成后 IP 地址会变更为目标机房的新 IP。

这个功能的核心逻辑：你付了套餐的钱，机房是可以在该套餐允许范围内自由选的，不满意随时切，不需要提工单、不需要重新购买。

## 切换数据中心之前，先搞清楚三件事

**第一，你的套餐是否支持迁移。**
搬瓦工不是所有套餐都能切机房的。部分特价限量版套餐绑定单一机房，购买页面或 KiwiVM 面板里没有迁移选项就是不支持。CN2 GIA-E（电商套餐）、KVM 常规套餐等主流套餐是支持的。

**第二，目标机房是否在你套餐的可选范围内。**
套餐等级决定机房上限，低级套餐无法迁到高级专属机房。KVM 常规套餐只能在 8 个基础机房里转，CN2 GIA-E 则能跑到 DC6、DC9、日本软银、荷兰联通等共 12+ 个节点。

**第三，IP 是否正常。**
IP 被封的情况下，KiwiVM 会直接拒绝迁移请求，需要先付费换 IP，再操作迁移。

## 搬瓦工切换数据中心步骤教程

以下步骤适用于所有支持迁移的套餐，操作一次大概 3 分钟，等待迁移完成需要 10～15 分钟。

**1. 登录搬瓦工客户后台**
进入 [bandwagonhost.com](https://bit.ly/bwhvps)，账号密码登录，点击顶部菜单 Services → My Services。页面会列出你名下所有 VPS 实例。

**2. 进入 KiwiVM 控制面板**
找到目标 VPS，点击实例右侧的 **KiwiVM Control Panel** 按钮，进入该 VPS 专属的控制面板。这是搬瓦工自研的面板，所有机房迁移、重装系统、查看流量都在这里操作。

**3. 找到 Migrate to another DC**
控制面板左侧菜单往下滑，找到 **Migrate** 区块，点击 **Migrate to another DC**。右侧会列出当前套餐允许迁移的所有目标机房，包含机房名称、线路类型和地区。

**4. 选择目标机房，确认迁移**
从列表中选择目标数据中心，点击 **Confirm on next step**，进入最终确认页。页面会提示：迁移期间 VPS 数据完整保留，最后阶段会有几秒到几分钟的短暂中断，迁移完成后 IP 地址会变更。确认无误后点击 **Start Migration**。

**5. 等待迁移完成，更新 DNS**
迁移过程一般 10～15 分钟，搬瓦工会发送邮件通知，邮件里会附上新的 IP 地址。如果你的 VPS 上绑了域名，记得去域名服务商更新 A 记录，等 DNS 生效（通常 5～30 分钟）后网站恢复正常。

> **注意**：切换机房前建议在 KiwiVM 中手动创建一个快照。正常迁移不会丢数据，但万一遇到极端情况（机房故障、网络中断等），有快照可以立刻回滚。

## 切换机房后需要做什么？

迁移完成不等于全部结束，还有几步收尾：

1. **更新域名 DNS**：KiwiVM 发邮件通知里会附新 IP，登录域名服务商把 A 记录改成新 IP，等待生效。
2. **清除 SSH known_hosts**：运行 `ssh-keygen -R 旧IP` 删掉旧的 host key，再用新 IP 重新连接。
3. **测试服务是否正常**：nginx/Apache/宝塔面板等服务在迁移过程中已自动保留，重新 SSH 进去用 `systemctl status nginx` 确认服务状态。
4. **更新任何硬编码了 IP 的配置**：如 Cloudflare 源服务器 IP、防火墙白名单、API 回调地址等。

## 常见问题 FAQ

### 切换机房要收费吗？

完全免费，也不限制次数。KiwiVM 控制面板里只要有 Migrate to another DC 选项，想切多少次都可以。

### 迁移会丢数据吗？

官方机制保证迁移过程中所有硬盘数据完整搬移，正常迁移不丢数据。不放心的话迁移前在 KiwiVM 里创建一个快照，零成本的保险。

### 迁移完成后 IP 一定会变吗？

是的，IP 会换成目标机房的新 IP。有一个例外：如果你从 A 机房迁到 B，再迁回 A，且之前在 A 的 IP 没被别人占用，会恢复成原来的 IP。

### KVM 套餐能迁移到 CN2 GIA 机房吗？

不能。套餐等级决定上限，KVM 常规套餐只能在基础机房间迁移，CN2 GIA 机房是 CN2 GIA-E 套餐及以上专属。

### 迁移过程多久？会影响业务吗？

迁移时间取决于 VPS 上已用的磁盘数据量，通常 10～15 分钟完成。在此期间 VPS 基本可操作，最后关机阶段仅持续几秒到几分钟，中断时间极短。

### IP 被封了还能迁移吗？

不行，IP 被封状态下 KiwiVM 会拒绝迁移请求。需要先通过 KiwiVM 付费更换 IP（$8.79 /次），IP 正常后再发起迁移。
